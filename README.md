# WETSCH – Industrial Editorial / Konzeptdemo V3

## So starten
`index.html` in einem aktuellen Browser öffnen. Keine Bibliotheken, kein Build, kein Server erforderlich.

## Designkonzept
Komplett neu gestaltete Website: warmes Papierweiß, Waldgrün und mineralisches Lime. Asymmetrisches Editorial-Layout, großflächige Material- und Maschinenwelt, individuelle Bildkacheln mit aktivem Leistungsdetail, Recycling-Infobereich, Recruiting und Kontakt. Keine Laufschrift, keine dekorativen Pfeile, keine wiederholten drei Standard-Karten oder nummerierten Abschnittsüberschriften.

## Logo und Fotografie
Das Wortzeichen `wetsch.` ist eine **frei gestaltete vorläufige typografische Wortmarke**, **kein bestätigtes Original-Logo**.
Die Foto-URLs zeigen externe Unsplash-Beispielfotos; sie sind nicht als Wetsch-Fahrzeuge oder Wetsch-Projekte verifiziert. Bei nicht verfügbarer Internetverbindung werden lokale, eigens erzeugte SVG-Illustrationen bzw. grafische Hintergründe angezeigt. Die lokale Grafik stellt kein reales Fahrzeug dar. Für eine offizielle Website Firmenfotos + Logo und Rechte bestätigen.
